# FuerteWaves web

Landing de previsión de surf de Fuerteventura (EN / ES / FR / DE): Inicio, Surfspots, Tiempo y Webcams.

- Oleaje: NOAA GFS Wave. Viento y tiempo: ECMWF IFS. Datos vía Open-Meteo (uso no comercial).
- Satélite: Meteosat © EUMETSAT. Mapa base: © Esri. Webcams: fuerteventuraplayas.com.
- Fuente Injekuta (CC0).
- Sitio estático (HTML/CSS/JS), sin build. Abrir `index.html` o publicar con GitHub Pages.

Las fichas de los spots (`js/data.js`) son un borrador pendiente de verificar.
